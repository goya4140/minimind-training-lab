## 固定模板需要人工解释的地方

- 模板用正确图关键词召回高于反事实来输出“视觉依赖已建立”。这是有限词面代理，
  不能证明通用视觉 grounding、幻觉控制或图序正确；单图错图和双图倒序需分别解读实际回答。
- 模板将正常/倒序 F1 和 loss 的正差称为时序敏感性证据。倒序仍对照原答案，不能当作倒序
  自身真值准确率，也不能单凭差值证明正确时序推理；检查逐样本正常/倒序回答和类别表现。
- 表格某些“PPL 相对变化”实际代码算的是绝对差 `after - before`。引用时明确为绝对差；
  相对百分比另算 `100 * (after / before - 1)`，不把两者混淆。
- 模板的 commit 是生成时 checkout HEAD，不自动表达混合 run 的全部训练来源。
  继承 LLM 引用父 run `53f9b9f...`，新多模态训练引用修复 run `9eafe5a...`，
  文档或工具发布 commit 另列；不能把文档更新说成训练中变更模型实现。
- 模板的训练图不是已经逐桶复算的全部最终 PNG；正式报告使用有 checkpoint SHA、CSV、
  统计定义与视觉 QA 的独立曲线。保留原始模板图作为不同生成方式的产物，不混称真实截图。
- 视频原汇总仅保存每组前 12 条回答，完整 100+160 条需要独立重放留存；
  即使原汇总已生成，不能声称完整逐样本输出已保留。
